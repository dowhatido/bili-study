# Bili Study · 哔哩学习札记

独立的 Edge / Chrome 浏览器扩展：把 B 站视频变成可以阅读、提问和保存的学习资料。与 YouTube Digest 不共用代码目录、配置或浏览器存储。

当前版本为工程验收版本，尚未完成真实 B 站账号及七家模型服务的端到端验收；不能据此承诺所有视频和模型均可用。产品范围及流程见 [PRD](PRD.md)，实际证据见 [验证记录](docs/verification.md)。

## 安装

1. 在 Edge 地址栏输入 `edge://extensions`，开启“开发人员模式”。
2. 点击“加载解压缩的扩展”，选择本项目目录（包含 `manifest.json` 的 `bili-study` 文件夹），或打包输出中的 `extension` 文件夹。
3. 固定“哔哩学习札记”到工具栏。打开 B 站并登录，进入一个带 CC 字幕的视频。
4. 点击扩展，进入“设置”，选择服务商，填写服务地址和访问密钥，点击“加载可用模型”，从下拉框选择文本对话模型，再保存。

不需要关闭或替换 YouTube Digest。不必将密钥发给开发者，也不要把密钥写进源码。

## 日常使用

- 视频侧栏：读取当前分 P 的字幕 → 生成课堂精读 → 围绕视频提问，点击来源时间回到视频。
- 个人沉淀：查看字幕、编辑精读、记录带时间点的笔记、整理讨论；导出字幕与精读 Markdown 或全部问答。
- 学习库：点击“添加内容”同步收藏夹或 UP 主作品，在统一列表中按全部、已整理、待整理和任务筛选。可以在设置中主动开启自动整理。
- 自己的作品：在“添加内容”中填入空间链接 → 同步作品 → 在学习库逐条整理，或按每轮上限批量入队。最多读取 10 页，超出会标记范围。
- 日报周报：同步实际观看与收藏记录后生成。周报为所选时区的周一至今；只把插件观察到的分享入口点击计入记录，不代表分享成功。
- Obsidian：在“设置 → 知识库”中选择仓库文件夹。保存到其下的 `Bili Study/视频资料`、`视频讨论`、`学习回顾`；也适用于任意普通文件夹。

当前仅保留 B 站来源字幕，不提供翻译、译文或双语阅读。新精读保留旧版本，可在“历史版本”查看。问答是插件自己的连续对话，不依赖其他聊天产品。

## 模型接入

| 服务 | 连接方式 | 模型选择 |
| --- | --- | --- |
| DeepSeek、OpenAI / GPT、xAI / Grok | OpenAI Chat Completions | 目标服务返回的模型列表 |
| MiniMax | OpenAI Chat Completions | 优先远端列表；官方地址的列表返回 404/405 时才用明确标记的官方目录 |
| 智谱 / GLM | OpenAI Chat Completions | 已核对的有限官方文本目录，不代表账号权限校验 |
| Anthropic / Claude | 原生 Messages | 原生列表与分页 |
| Google / Gemini | 原生 generateContent | 原生列表与分页 |
| 自定义网关 | 上述三类任选 | 必须真实返回列表，不提供手填模型 ID 或伪造选项 |

列表可见不等于可用于文本学习，也不代表账号有额度或权限。部分新模型只支持其他端点，或需要特定推理参数；当前不承诺兼容厂商所有型号。详细请求、安全边界和官方依据见 [模型协议](docs/model-protocols.md)。

预设使用 HTTPS。自定义 HTTP 地址会在连接时要求风险确认：密钥及内容将以明文发送。服务地址变化不会把旧地址的保存密钥发送到新地址；所有请求拒绝重定向。

## 自动化和费用

自动整理、自动报告都默认关闭。开启后使用你配置的模型，产生的服务费用由服务商决定。收藏每 30 分钟检查，单轮上限可设为 1–50 个视频；多分 P 收藏先整理第一 P，其他分 P 从相应视频页读取。当前没有月度预算或金额硬封顶。

只在浏览器运行、B 站页面可访问且登录有效时同步，不安装常驻程序。报告按所选时区在设定小时之后生成当天报告，周日生成本周报告；不补跑关机期间的全部历史报告。没有符合日期的记录时不会编造报告。

服务工作线程中断的任务会停为“处理已中断”，不自动重复可能收费的请求；失败／取消的自动任务也不会在每次同步中反复重新生成。手动重试前需再次确认，仍可能重复计费。保存失败不会触发重新生成。

## 数据与限制

- 字幕通过 B 站网页使用的登录态请求路径取得，不是面向第三方承诺稳定的官方开放平台授权。未绕过付费、风控或不可访问内容。无字幕视频不自动转写。
- 扩展不读取或导出 Cookie，模型服务不接收 B 站 Cookie。字幕与相关记录在你使用对应功能时发送给所选模型服务。
- 收藏和历史均有分页边界；超出范围会提示，不宣称完整历史。没有可信收藏时间的存量视频不计为当日新增。
- 长字幕分批总结；问答超长视频只检索相关片段并标明范围，不等于全片取证。讨论整理超过 70,000 字符或报告输入超过 80,000 字符会明确停止，完整对话仍可导出，绝不静默截尾。
- 资料保存在本浏览器的本地存储，未实现云同步、全文检索本地知识库、ASR、音视频生成或自动操作分享。浏览器存储有容量限制；不会自动删除旧资料腾空间。
- 本地保存由用户主动点击，新增快照，写后读回校验。不扫描既有笔记、不修改旧文件；检测到同名文件会停止。尚未实现跨进程原子创建、重复意图回执恢复或后台自动写入 Obsidian。
- 密钥保存于本机浏览器扩展存储，非操作系统保险箱。其他有本机管理权限的人员或软件仍可能访问，不承诺端到端加密保险库。

## 开发和验证

Node.js 22 或更新版本，无运行时依赖。

```sh
npm test
npm run check
npm run preview
npm run package
```

模型调用不是一次把整段视频直接发送：精读会按字幕长度分批，单任务内最多同时处理 2 个批次，再根据全部笔记生成一次导读与复习材料；问答只发起一次请求。并发数固定有上限，避免视频越长、请求越多。

预览仅用于页面检查，不包含扩展后台能力。打包只收录运行文件，逐文件校验 ZIP 和解压目录；不会打包文档、测试、用户资料或浏览器配置，也不删除旧包。操作细节见 [接入说明](docs/bilibili-access.md)、[验收方案](docs/acceptance.md) 与 [架构说明](docs/architecture.md)。

已经建立 [AGENTS.md](AGENTS.md) 和 PRD。需求、实现或验证状态变化时应同步更新；本版本尚不是完成实机验收的正式发布。
