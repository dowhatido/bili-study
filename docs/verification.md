## 与 PRD 的差距（未达成或部分达成）

- 严格租约与“恰好一次”计费无法保证：运行身份校验、中断转“处理已中断”、取消／清除后的迟到写回保护均已实现并有测试；但跨进程原子创建、持久化导出意图回执、上游幂等键仍未提供证据。
- 字幕与摘要的完整版本图未实现：同一视频重新读取不会自动探测字幕修订并生成新版本；摘要与报告保留旧版本，字幕本身按分集缓存。
- 本地知识库未实现后台自动写入与跨进程不覆盖保证：当前为手动保存 + 已有名拒写 + 写后读回 + 同源浏览器锁。
- 自动化周期参数、保守值与上限为实现者安全默认值，未经用户批准；无月度预算硬封顶。
- 页面已检查五态与响应式，但未执行真实键盘全流程与屏幕阅读器验收。

## 结论

0.9.1 已完成信息架构重构和 AI 批次并行提速，并通过 230 项离线测试和本地浏览器响应式检查。可交付的是当前工程构建和已验证的界面结构、并发上限与批次检查点；不可宣称的是所有 B 站视频都能取到字幕、任何模型都兼容、真实服务一定不会限流、AI 输出无需人工复核、批量自动化不会重复计费，或最新包已经在目标 Edge 完成全链路验收。首次实机使用建议按 README 顺序逐项验证，发现问题先看本文件的未执行项是否命中。
